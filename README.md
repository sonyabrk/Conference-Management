# Система управления конференциями

## Назначение
Приложение для организации научных и технических конференций: 
учёт секций, регистрация докладов авторов, распределение докладов 
по секциям и тайм-слотам, отслеживание статуса заявок.

## Целевая аудитория
Организаторы конференций, ответственные за формирование программы 
мероприятия и координацию докладов.

## Предметная область
Проведение конференции предполагает деление на тематические секции, 
в рамках которых авторы представляют доклады в отведённое время. 
Система позволяет фиксировать секции, принимать заявки на доклады, 
проверять занятость слотов и вести учёт участников.

## Основные сущности
- конференция;
- секция;
- доклад;
- автор.

## Возможности (актуально после ПР2)
- просмотр и поиск секций/конференций;
- проверка вместимости секции;
- сортировка секций по вместимости;
- отбор секций по количеству свободных мест;
- проверка доступности тайм-слота для доклада;
- добавление заявки на доклад;
- отмена заявки на доклад.

## Структура проекта
- main.py — точка запуска, меню приложения;
- conferences.py — работа с конференциями и секциями;
- talks.py — работа с докладами (заявками);
- storage.py — сохранение и загрузка данных (JSON);
- utils.py — вспомогательные функции (безопасный ввод);
- data/ — JSON-файлы данных;
- tests/ — автоматизированные тесты.

## Требования
- Python 3.x;
- pytest;
- flake8.

Установка зависимостей:
pip install -r requirements.txt

## Запуск программы
python main.py

## Запуск тестов
python -m pytest

## Проверка качества кода
flake8
